## 文件整体功能
这段代码**演示了 `std::vector`（动态数组）的基本操作**：创建、添加元素、访问元素、遍历以及删除元素，最后输出每一步的结果。

---

## 逐段详细解释

### 1. 头文件引入
cpp 
#include <iostream>   // 用于输入输出，如 std::cout、std::endl
#include <vector>     // 用于使用 std::vector 容器
- `iostream` 让你能在屏幕上打印文字。
- `vector` 包含 `std::vector` 的定义，必须引入才能用。

### 2. main 函数开始
cpp 
int main() {
    // 创建一个空的整数 vector
    std::vector<int> nums;
- `std::vector<int>` 是一个存放 `int` 类型元素的动态数组。
- `nums` 是它的名字，现在是空的，里面没有任何数字。

### 3. 添加元素（push_back）
cpp 
    nums.push_back(10);
    nums.push_back(20);
    nums.push_back(30);
- `push_back` 是在向量的末尾添加新元素。
- 执行完这三句后，`nums` 里就有了三个数字：`[10, 20, 30]`（顺序就是添加的顺序）。

### 4. 查看大小和访问元素
cpp 
    std::cout << "vector 大小: " << nums.size() << std::endl;
- `size()` 返回当前元素个数。
- 这里会输出 `vector 大小: 3`。
cpp 
    std::cout << "第一个元素: " << nums[0] << std::endl;
    std::cout << "第二个元素: " << nums.at(1) << std::endl; // at 会检查越界
- `nums[0]` 是下标访问，像普通数组一样，`0` 是第一个元素（10）。
- `nums.at(1)` 是第二种访问方式，`1` 是第二个元素（20）。
- **区别**：`at()` 会检查下标是否越界，如果越界会抛出异常，而 `[]` 不检查，越界是未定义行为。

### 5. 用范围 for 循环遍历
cpp 
    std::cout << "全部元素: ";
    for (int x : nums) {
        std::cout << x << " ";
    }
    std::cout << std::endl;
- 这是 C++11 引入的范围 for 循环。`int x` 每次取出 `nums` 中的一个元素，从第一个到最后一个。
- 效果：会打印 `10 20 30`，每个数字用空格隔开，最后换行。

### 6. 删除最后一个元素（pop_back）
cpp 
    nums.pop_back();
    std::cout << "pop 后大小: " << nums.size() << std::endl;
- `pop_back()` 删除末尾元素（这里是 30），不返回被删的值。
- 删完后 `nums` 里剩下 `[10, 20]`，所以 `size()` 变成 2。
- 输出：`pop 后大小: 2`。

### 7. 结束
cpp 
    return 0;
}
- 主函数正常结束，返回 0 表示程序成功。

## 老师的一点引申
- 如果用 `nums.at(3)` 去访问第四个元素（不存在），程序会抛出 `std::out_of_range` 异常，比 `nums[3]` 更安全。
- 如果想要在开头或中间插入元素，可以研究一下 `insert()` 成员函数。
- 如果你需要存放数学向量，`std::vector` 可以当坐标容器，比如 `std::vector<double> vec = {1.0, 2.0, 3.0};` 表示三维空间中的向量。
